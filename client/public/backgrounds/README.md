# Thư mục Ảnh Nền (Backgrounds)

Dự án hỗ trợ thay đổi cảnh nền livestream linh hoạt (thủ công hoặc tự động chuyển cảnh theo thời gian).

### Các ảnh nền có sẵn:
- **`mountain-mist.jpg`**: Cảnh thung lũng núi non mây mù hùng vĩ buổi sáng (mẫu chuẩn).
- **`sunset-clouds.jpg`**: Cảnh hoàng hôn chân mây rực rỡ lãng mạn.
- **`cozy-lofi.jpg`**: Cửa sổ phòng Lofi nhìn ra thành phố đêm.
- **`cyberpunk.jpg`**: Thành phố tương lai ánh đèn neon rực rỡ.

### Cách thêm ảnh nền của riêng bạn:
1. Bạn chỉ cần thả các file ảnh `.jpg`, `.jpeg`, `.png`, hoặc `.webp` vào thư mục này.
2. Đặt tên file ngắn gọn, ví dụ: `my-room.jpg`, `nature-1.jpg`.
3. Vào trang Admin `/admin` hoặc bảng điều khiển để chọn ảnh vừa thêm, hoặc bật chế độ **Tự động đổi cảnh** để hệ thống tự xoay vòng các ảnh nền!
